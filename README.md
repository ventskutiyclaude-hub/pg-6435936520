# Яхтенная поездка Гёчек, 3–10.10.2026

Два самодостаточных HTML-отчёта (карты, глубины, прогноз ветра, расчёт ходовых миль, чек-листы, схемы яхты):

- `report-gocek.html` — основной маршрут от Гёчека
- `report-kas.html` — вариант в сторону Каша

Как открыть: скачайте файл (Raw → Save as…) и откройте в браузере. Файлы работают без интернета, нужен JavaScript.
Репозиторий приватный: в отчётах состав экипажа, даты и название яхты.
